1. Unzip this package.
2. Upload all 8 HTML files into the ROOT of your existing GitHub repository.
3. Upload BOTH files from assets/ INTO THE EXISTING assets folder.
   Keep all existing ZAVRA assets — DO NOT delete or replace the folder.
4. Commit. Your Render Static Site can auto-deploy from main.
5. Hard refresh the live page (Ctrl+Shift+R) to see the latest design.
